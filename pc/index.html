    Connect your phone

    Enable USB debugging, connect a data cable, and accept the authorization prompt.

    npm run connect:usb

    Run npm start, then tap Start streaming on your phone.

    Android 8+No Wi-Fi needed

    On Android 11+, connect both devices to the same Wi-Fi. Enable Developer options > Wireless debugging > Pair device with pairing code.

    npm run connect:wireless -- -Pair

    Enter the pairing address and code when prompted, then the connection address from the main Wireless debugging page. These ports are different.

    npm run connect:wireless

    Use this shorter command after pairing. Run npm start and tap Start streaming. No USB cable is required.

    Android 11+Same Wi-Fi

    These buttons show setup instructions. Run the commands in the project terminal. For a manually installed APK, use npm run connect:prebuilt:usb or npm run connect:prebuilt:wireless (add -- -Pair for first-time wireless pairing). Source commands also reuse installed apps; pass -- -Reinstall after rebuilding.

    Orientation notes

    The model uses Android's device axes and quaternion to update its 3D pose. Heading comes from the phone's fused rotation sensor and can drift or be affected by nearby magnetic sources. Keep the companion app open during streaming.
